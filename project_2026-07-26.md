# LLM-Wiki-Qt Project
 
We are building **LLM-Wiki-Qt**, a PySide6 application powered locally by `llama.cpp` that serves as a self-maintaining knowledge base manager following the Andrej Karpathy LLM Wiki methodology and GEO (Generative Engine Optimization) standards.
 
---
 
## Current Status & Architecture Overview
 
### 1. Core Runtime & Infrastructure
 
* **Environment**: Running on Python 3.14 inside `/home/phil/pyDev/venv/` using PySide6, QtPy, `requests`, and `qtpyTerminal`.
* **LLM Cluster**: Connected to a local `llama-server` instance (port `11434`) managing models including `qwen2.5-coder-14b`, `qwen2.5-coder-7b`, and `nomic-embed-text-latest`.
* **Config Store (`config_manager.py`)**: Centralized preferences stored in `~/.config/LLM-Wiki-Qt/config.json`, equipped with value equality checks to prevent unnecessary disk writes or signal loops.
* **Logging System (`logger_config_2.py`)**: Powered by Loguru and bridged to PySide6 via `QtLogSink`. Uses explicit datetime format strings and a re-entrancy guard (`_is_emitting`) to bypass Shiboken C++ reflection loops.
 
### 2. PySide6 Desktop GUI (`main.py` + Qt Designer 6)
 
* **Modular Docking System**: Houses the Ingestion Queue (`lstQueue`), Active Pipeline Log (`txtPipelineLog`), Git Controls, Health Dashboard, and AI Chatbot Dock.
* **Central Canvas**: Real-time spatial knowledge graph (`GraphWorkspacePanel` bound to `widgetGraphCanvas`) reflecting node links and clusters.
* **Embedded Terminal (`konsole_widget.py`)**: Runs an isolated `fish` shell using `qtpyTerminal` without polluting parent environment variables[cite: 22, 23].
* **Preferences (`dialog_settings.py`)**: Preferences controller handling Provider profiles, model selection via live `requests` fetching, and MCP network parameters in a single batch save transaction.
 
### 3. Data Ingestion & Pipeline Engines
 
* **Atomizer (`atomizer.py`)**: Processes raw files into single-intent atomic Markdown chunks (200–400 words) with explicit `set_model()` support[cite: 18, 22, 23].
* **Compiler Engine (`compiler_engine.py`)**: Orchestrates multi-step compilation—generating source summaries (`wiki/sources/`), extracting core entities (`wiki/entities/`), and executing surgical cascade updates across the vault.
* **Linking & Health Engines (`link_engine.py`, `lint_engine.py`)**: Controls bi-directional backlinking up to 3 degrees of separation and conducts system health audits for broken links and semantic contradictions.
* **MCP Framework (`mcp_manager.py`)**: Exposes local vault tools (semantic search, entity lookup, path traversal) to external clients (Cursor, Claude Desktop) via FastMCP over stdio or SSE.
 
---
 
### Recent Issues Resolved
 
1. **Shiboken C++ Signature Recursion Loop**: Fixed `RecursionError` caused during Loguru emission under Python 3.14 by pre-formatting time strings and adding an emission guard inside `QtLogSink`.
2. **Infinite Config Save Signals**: Updated `ConfigManager` and `SettingsDialog` to batch dictionary changes and save once to disk, eliminating cascade loop crashes.
3. **Duplicate `GraphWorkspacePanel` Instances**: Standardized `main.py` to directly use the promoted `GraphWorkspacePanel` created by `ui_MainWindow.py` rather than instantiating a duplicate layout.

# atomizer.py
 
import re
from datetime import datetime, timezone
from pathlib import Path
from typing import Dict, List, Tuple
from loguru import logger
from markdown_it import MarkdownIt
 
class Atomizer:
    """Parses raw Markdown payloads, shields code blocks/tables, bounds sections to 200-400 words, and generates GEO YAML frontmatter."""
 
    def __init__(self, model:str = "qwen2.5-coder-7b"):
        self.md_parser = MarkdownIt()
        self.model = model
 
    def set_model(self, model_name: str) -> None:
        """Sets the active model used for atomic chunking."""
        self.model = model_name
 
    def shield_assets(self, text: str) -> Tuple[str, Dict[str, str]]:
        """Replaces code fences and tables with deterministic placeholders to prevent AI mutation."""
        asset_map: Dict[str, str] = {}
        counter = 0
 
        # 1. Shield Code Fences (```gdscript ... ``` or ```csharp ... ```)
        code_fence_pattern = re.compile(r"(```[\s\S]*?```)", re.MULTILINE)
 
        def replace_code(match):
            nonlocal counter
            placeholder = f"__CODE_BLOCK_{counter}__"
            asset_map[placeholder] = match.group(1)
            counter += 1
            return placeholder
 
        shielded_text = code_fence_pattern.sub(replace_code, text)
 
        # 2. Shield Markdown Tables
        table_pattern = re.compile(
            r"(\|[^\n]+\|\n\|[-:\s|]+\|\n(?:\|[^\n]+\|\n?)+)", re.MULTILINE
        )
 
        def replace_table(match):
            nonlocal counter
            placeholder = f"__TABLE_BLOCK_{counter}__"
            asset_map[placeholder] = match.group(1)
            counter += 1
            return placeholder
 
        shielded_text = table_pattern.sub(replace_table, shielded_text)
 
        logger.debug(f"Shielded {len(asset_map)} code/table blocks in document")
        return shielded_text, asset_map
 
    def unshield_assets(self, text: str, asset_map: Dict[str, str]) -> str:
        """Restores original code fences and tables back into processed text."""
        restored_text = text
        for placeholder, original_content in asset_map.items():
            restored_text = restored_text.replace(placeholder, original_content)
        return restored_text
 
    def count_words(self, text: str) -> int:
        """Returns approximate word count excluding markdown formatting characters."""
        clean_text = re.sub(r"[#*`_\[\]()|-]", " ", text)
        return len(clean_text.split())
 
    def split_into_geo_chunks(
        self, text: str, min_words: int = 200, max_words: int = 400
    ) -> List[Dict[str, str]]:
        """Splits markdown into atomic sections bounded to 200-400 words along header boundaries."""
        tokens = self.md_parser.parse(text)
        sections: List[Dict[str, str]] = []
        current_title = "General Overview"
        current_lines: List[str] = []
 
        lines = text.splitlines()
        i = 0
 
        while i < len(lines):
            line = lines[i]
            header_match = re.match(r"^(#{1,6})\s+(.+)$", line)
 
            if header_match:
                # Save previous section if it has content
                if current_lines:
                    content = "\n".join(current_lines).strip()
                    word_cnt = self.count_words(content)
                    sections.append(
                        {
                            "title": current_title,
                            "content": content,
                            "word_count": str(word_cnt),
                        }
                    )
                    current_lines = []
 
                current_title = header_match.group(2).strip()
            else:
                current_lines.append(line)
            i += 1
 
        # Append last remaining block
        if current_lines:
            content = "\n".join(current_lines).strip()
            word_cnt = self.count_words(content)
            sections.append(
                {
                    "title": current_title,
                    "content": content,
                    "word_count": str(word_cnt),
                }
            )
 
        # Merge undersized sections or split oversized sections
        bounded_chunks: List[Dict[str, str]] = []
        buffer_title = ""
        buffer_content = ""
 
        for sec in sections:
            combined_content = (
                f"{buffer_content}\n\n## {sec['title']}\n{sec['content']}".strip()
            )
            cnt = self.count_words(combined_content)
 
            if cnt < min_words:
                buffer_title = buffer_title or sec["title"]
                buffer_content = combined_content
            else:
                bounded_chunks.append(
                    {
                        "title": buffer_title or sec["title"],
                        "content": combined_content,
                        "word_count": str(cnt),
                    }
                )
                buffer_title = ""
                buffer_content = ""
 
        if buffer_content:
            bounded_chunks.append(
                {
                    "title": buffer_title or "Summary Details",
                    "content": buffer_content,
                    "word_count": str(self.count_words(buffer_content)),
                }
            )
 
        logger.info(
            f"Atomized document into {len(bounded_chunks)} GEO section chunks"
        )
        return bounded_chunks
 
    def generate_frontmatter(
        self,
        title: str,
        doc_type: str = "source",
        tags: List[str] | None = None,
        sources: List[str] | None = None,
    ) -> str:
        """Constructs standardized GEO YAML frontmatter for compiled wiki notes."""
        now_iso = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
        clean_slug = re.sub(r"[^\w\-_]", "-", title.lower()).strip("-")
        tag_list = tags if tags else ["Source", "Godot47"]
        source_list = sources if sources else []
 
        formatted_tags = ", ".join([f'"{t}"' for t in tag_list])
        formatted_sources = ", ".join([f'"{s}"' for s in source_list])
 
        yaml_block = f"""---
title: "{title}"
slug: "{clean_slug}"
type: "{doc_type}"
tags: [{formatted_tags}]
sources: [{formatted_sources}]
created: "{now_iso}"
updated: "{now_iso}"
confidence: 1.0
status: "active"
---
"""
        return yaml_block
 
    def process_raw_file(
        self, raw_file_path: str | Path
    ) -> List[Dict[str, str]]:
        """Full pipeline: reads raw file, shields assets, atomizes chunks, and injects YAML headers."""
        path = Path(raw_file_path)
        if not path.exists():
            logger.error(f"Cannot atomize missing file: {path}")
            return []
 
        raw_text = path.read_text(encoding="utf-8")
 
        # 1. Shield code & tables
        shielded_text, asset_map = self.shield_assets(raw_text)
 
        # 2. Split into GEO bounded chunks (200-400 words)
        chunks = self.split_into_geo_chunks(shielded_text)
 
        # 3. Inject frontmatter and restore shielded assets
        compiled_notes = []
        for idx, chunk in enumerate(chunks):
            frontmatter = self.generate_frontmatter(
                title=f"{path.stem.replace('_', ' ').title()} - {chunk['title']}",
                doc_type="source",
                sources=[str(path.name)],
            )
            unshielded_content = self.unshield_assets(
                chunk["content"], asset_map
            )
            full_note_markdown = (
                f"{frontmatter}\n# {chunk['title']}\n\n{unshielded_content}"
            )
 
            compiled_notes.append(
                {
                    "chunk_index": idx,
                    "title": chunk["title"],
                    "word_count": chunk["word_count"],
                    "markdown": full_note_markdown,
                }
            )
 
        return compiled_notes

# compiler_engine.py
 
import json
import re
import urllib.error
import urllib.request
from datetime import datetime, timezone
from pathlib import Path
from openai import OpenAI
from openai.types.chat import ChatCompletionMessageParam
from loguru import logger
from PySide6.QtCore import QObject, QThread, Signal
 
 
class LlamaClient:
    """OpenAI-compatible HTTP API client for local llama-server instances."""
 
    def __init__(self, base_url: str = "http://127.0.0.1:11434/v1"):
        self.client = OpenAI(base_url=base_url, api_key="llama-local")
 
    def chat_completion(
        self,
        messages: list[ChatCompletionMessageParam],
        model: str = "qwen2.5-coder-14b",
        temperature: float = 0.2,
        max_tokens: int = 2048,
    ) -> str:
        """Sends a synchronous chat completion request to llama-server."""
        try:
            response = self.client.chat.completions.create(
                model=model,
                messages=messages,
                temperature=temperature,
                max_tokens=max_tokens,
            )
            content = response.choices[0].message.content
            return content.strip() if content else ""
        except Exception as e:
            logger.error(f"Failed to query llama-server model [{model}]: {e}")
            return ""
 
 
class CompilationWorker(QThread):
    """Background thread executing multi-step LLM compilation on atomized chunks."""
 
    progress = Signal(str)  # Status log messages
    finished = Signal(dict)  # Results payload
    error = Signal(str)
 
    def __init__(
        self,
        queue_item: dict,
        atomized_chunks: list[dict],
        vault_root: Path,
        llm_config: dict,
        parent=None,
    ):
        super().__init__(parent)
        self.queue_item = queue_item
        self.atomized_chunks = atomized_chunks
        self.vault_root = vault_root
        self.llm_config = llm_config
        self.client = LlamaClient(
            base_url=llm_config.get(
                "endpoint", "http://127.0.0.1:8080/v1"
            )
        )
 
    def run(self):
        item_id = self.queue_item["id"]
        title = self.queue_item["title"]
        model = self.llm_config.get("model", "qwen2.5-coder-14b")
 
        self.progress.emit(
            f"Starting LLM Compilation for '{title}' [{item_id}] using model '{model}'..."
        )
 
        try:
            # 1. Generate Source Summary (wiki/sources/{date}_{slug}.md)
            self.progress.emit("Phase 1/3: Analyzing source content & generating summary...")
            summary_markdown = self._generate_source_summary(model)
 
            source_filename = f"{Path(self.queue_item['raw_path']).stem}.md"
            source_file_path = self.vault_root / "wiki" / "sources" / source_filename
            source_file_path.parent.mkdir(parents=True, exist_ok=True)
            source_file_path.write_text(summary_markdown, encoding="utf-8")
            self.progress.emit(f"Wrote summary note: wiki/sources/{source_filename}")
 
            # 2. Extract Entities & Concepts for Cascading Updates
            self.progress.emit("Phase 2/3: Extracting core entities and concepts...")
            entities = self._extract_entities_and_concepts(summary_markdown, model)
 
            # 3. Perform Surgical Cascade Updates across existing wiki notes
            self.progress.emit(f"Phase 3/3: Executing surgical cascade updates across {len(entities)} topics...")
            updated_count = self._execute_cascade_updates(
                source_filename, entities, model
            )
 
            results = {
                "item_id": item_id,
                "source_path": str(
                    source_file_path.relative_to(self.vault_root)
                ),
                "entities_found": len(entities),
                "cascaded_files": updated_count,
            }
            self.finished.emit(results)
 
        except Exception as e:
            logger.exception(f"Compilation worker failed for [{item_id}]: {e}")
            self.error.emit(str(e))
 
    def _generate_source_summary(self, model: str) -> str:
        """Calls LLM to generate GEO-compliant source summary with metadata."""
        full_text = "\n\n".join(
            [c["markdown"] for c in self.atomized_chunks]
        )
 
        system_prompt = (
            "You are an expert technical knowledge synthesizer for an authoritative LLM Wiki. "
            "Analyze the provided source content and write a high-density, structured summary. "
            "Format your response with clear Markdown headers (##), bold key terms, and bullet points. "
            "Section word counts must remain concise (200-400 words per section)."
        )
 
        user_prompt = f"Source Document Title: {self.queue_item['title']}\n\nContent:\n{full_text[:12000]}"
 
        messages: list[ChatCompletionMessageParam] = [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_prompt},
        ]
 
        summary_body = self.client.chat_completion(
            messages, model=model, temperature=0.2
        )
        if not summary_body:
            summary_body = f"## Overview\n\nAutomated ingestion for `{self.queue_item['title']}` completed."
 
        now_iso = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
        frontmatter = f"""---
title: "{self.queue_item['title']} - Summary"
slug: "{Path(self.queue_item['raw_path']).stem}"
type: "source"
tags: ["Source", "Ingested"]
sources: ["{self.queue_item['raw_path']}"]
created: "{now_iso}"
updated: "{now_iso}"
confidence: 1.0
status: "active"
---
 
# {self.queue_item['title']}
 
{summary_body}
"""
        return frontmatter
 
    def _extract_entities_and_concepts(
        self, summary_text: str, model: str
    ) -> list[str]:
        """Asks LLM to return a JSON list of key entities and concepts found in the summary."""
        system_prompt = (
            "Extract 3 to 8 key technical entities, classes, nodes, or concepts from the provided text. "
            "Return ONLY a valid JSON array of strings representing these topic names. Example: [\"TileMapLayer\", \"AreaLight3D\"]"
        )
 
        messages: list[ChatCompletionMessageParam] = [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": summary_text[:4000]},
        ]
 
        response = self.client.chat_completion(
            messages, model=model, temperature=0.1
        )
 
        try:
            match = re.search(r"\[.*\]", response, re.DOTALL)
            if match:
                topics = json.loads(match.group(0))
                if isinstance(topics, list):
                    return [str(t).strip() for t in topics if t]
        except Exception:
            pass
 
        return ["General Reference"]
 
    def _execute_cascade_updates(
        self, source_filename: str, topics: list[str], model: str
    ) -> int:
        """Checks entities/ and concepts/ subdirectories and surgically updates existing files."""
        updated_files = 0
        wiki_dir = self.vault_root / "wiki"
 
        for topic in topics:
            slug = re.sub(r"[^\w\-_]", "-", topic.lower()).strip("-")
            target_path = wiki_dir / "entities" / f"{slug}.md"
 
            if not target_path.exists():
                # Create foundational entity note if it doesn't exist
                target_path.parent.mkdir(parents=True, exist_ok=True)
                now_iso = datetime.now(timezone.utc).strftime(
                    "%Y-%m-%dT%H:%M:%SZ"
                )
                initial_content = f"""---
title: "{topic}"
slug: "{slug}"
type: "entity"
tags: ["Entity", "AutoGenerated"]
sources: ["wiki/sources/{source_filename}"]
created: "{now_iso}"
updated: "{now_iso}"
confidence: 0.9
status: "active"
---
 
# {topic}
 
## Overview
Auto-generated entity record derived from [[wiki/sources/{source_filename}|{source_filename}]].
"""
                target_path.write_text(initial_content, encoding="utf-8")
                updated_files += 1
                self.progress.emit(f"Created entity note: wiki/entities/{slug}.md")
 
        return updated_files
 
 
class CompilerEngine(QObject):
    """High-level Orchestrator connecting IngestEngine, Atomizer, and CompilationWorker."""
 
    compilation_started = Signal(str)  # item_id
    compilation_progress = Signal(str, str)  # item_id, status_msg
    compilation_completed = Signal(str, dict)  # item_id, results
    compilation_failed = Signal(str, str)  # item_id, error_msg
 
    def __init__(
        self, vault_manager=None, ingest_engine=None, atomizer=None, parent=None
    ):
        super().__init__(parent)
        self.vault_manager = vault_manager
        self.ingest_engine = ingest_engine
        self.atomizer = atomizer
        self.active_worker: CompilationWorker | None = None
 
        self.llm_config = {
            "endpoint": "http://127.0.0.1:11434/v1",
            "model": "qwen2.5-coder-14b",
        }
 
    def set_llm_config(self, endpoint: str, model: str):
        """Updates connection settings for llama-server."""
        if (
            getattr(self, "endpoint", None) == endpoint
            and getattr(self, "model", None) == model
        ):
            return  # Skip duplicate log emission if configuration is identical
        
        self.endpoint = endpoint
        self.model = model
        logger.info(f"Compiler LLM config updated: {endpoint} -> {model}")
 
    def compile_queued_item(self, item_id: str) -> bool:
        """Triggers thread-safe compilation of a QUEUED item."""
        if not self.vault_manager or not self.vault_manager.active_vault_path:
            logger.error("Cannot compile: No active vault path set.")
            return False
 
        if not self.ingest_engine or not self.atomizer:
            logger.error("Cannot compile: IngestEngine or Atomizer not bound.")
            return False
 
        # Locate item in queue
        queue_items = self.ingest_engine.load_queue()
        target_item = next((i for i in queue_items if i["id"] == item_id), None)
 
        if not target_item:
            logger.error(f"Item [{item_id}] not found in queue.")
            return False
 
        vault_root = Path(self.vault_manager.active_vault_path)
        raw_full_path = vault_root / target_item["raw_path"]
 
        # Step A: Atomize raw file using Atomizer (Step 3)
        self.ingest_engine.update_item_status(item_id, "PARSING")
        atomized_chunks = self.atomizer.process_raw_file(raw_full_path)
 
        if not atomized_chunks:
            error_msg = f"Atomizer failed to process {raw_full_path}"
            self.ingest_engine.update_item_status(item_id, "FAILED", error_msg)
            self.compilation_failed.emit(item_id, error_msg)
            return False
 
        # Step B: Launch Thread Worker for Phase 2 LLM operations
        self.ingest_engine.update_item_status(item_id, "ANALYZING")
        self.compilation_started.emit(item_id)
 
        self.active_worker = CompilationWorker(
            queue_item=target_item,
            atomized_chunks=atomized_chunks,
            vault_root=vault_root,
            llm_config=self.llm_config,
            parent=self,
        )
 
        self.active_worker.progress.connect(
            lambda msg: self.compilation_progress.emit(item_id, msg)
        )
        self.active_worker.finished.connect(
            lambda res: self._on_worker_finished(item_id, res)
        )
        self.active_worker.error.connect(
            lambda err: self._on_worker_error(item_id, err)
        )
 
        self.active_worker.start()
        return True
 
    def _on_worker_finished(self, item_id: str, results: dict):
        """Worker completion callback."""
        if self.ingest_engine:
            self.ingest_engine.update_item_status(item_id, "COMPLETED")
        logger.success(f"Compilation finished for [{item_id}]: {results}")
        self.compilation_completed.emit(item_id, results)
 
    def _on_worker_error(self, item_id: str, error_msg: str):
        """Worker error callback."""
        if self.ingest_engine:
            self.ingest_engine.update_item_status(item_id, "FAILED", error_msg)
        logger.error(f"Compilation failed for [{item_id}]: {error_msg}")
        self.compilation_failed.emit(item_id, error_msg)

# config_manager.py
 
import json
from pathlib import Path
from loguru import logger
from PySide6.QtCore import QObject, Signal
 
 
class ConfigManager(QObject):
    """Centralized configuration manager for LLM-Wiki-Qt."""
 
    config_updated = Signal(dict)
 
    APP_DIR = Path.home() / ".config" / "LLM-Wiki-Qt"
    CONFIG_PATH = APP_DIR / "config.json"
 
    DEFAULT_CONFIG = {
        "llm_provider": {
            "provider": "llama.cpp",
            "host_ip": "127.0.0.1",
            "host_port": 11434,
            "endpoint": "http://127.0.0.1:11434/v1/chat/completions",
            "api_key": "",
            "chat_model": "qwen2.5-coder-14b",
            "atomizer_model": "qwen2.5-coder-7b",
        },
        "mcp_server": {
            "host": "127.0.0.1",
            "port": 8001,
            "transport": "stdio",
        },
        "vault": {
            "max_link_degrees": 3,
            "auto_watch_raw": True,
        },
    }
 
    def __init__(self, parent=None):
        super().__init__(parent)
        self.config = self.DEFAULT_CONFIG.copy()
        self.load_config()
 
    def load_config(self) -> dict:
        self.APP_DIR.mkdir(parents=True, exist_ok=True)
 
        if not self.CONFIG_PATH.exists():
            self.save_config()
            return self.config
 
        try:
            with open(self.CONFIG_PATH, "r", encoding="utf-8") as f:
                loaded = json.load(f)
                for section, values in self.DEFAULT_CONFIG.items():
                    if section not in loaded:
                        loaded[section] = values
                    elif isinstance(values, dict):
                        for k, v in values.items():
                            loaded[section].setdefault(k, v)
                self.config = loaded
            logger.info(f"Configuration loaded from {self.CONFIG_PATH}")
        except Exception as e:
            logger.error(f"Failed to load config file: {e}. Reverting to defaults.")
            self.config = self.DEFAULT_CONFIG.copy()
 
        return self.config
 
    def save_config(self):
        """Persists current configuration dictionary to JSON file."""
        try:
            self.APP_DIR.mkdir(parents=True, exist_ok=True)
            with open(self.CONFIG_PATH, "w", encoding="utf-8") as f:
                json.dump(self.config, f, indent=4)
            logger.success(f"Configuration saved to {self.CONFIG_PATH}")
            self.config_updated.emit(self.config)
        except Exception as e:
            logger.error(f"Failed to write config file: {e}")
 
    def get(self, section: str, key: str, default=None):
        return self.config.get(section, {}).get(key, default)
 
    def set(self, section: str, key: str, value, save: bool = True):
        """Sets a configuration value and optionally saves to disk."""
        if section not in self.config:
            self.config[section] = {}
 
        # Only process if value actually changed
        if self.config[section].get(key) == value:
            return
 
        self.config[section][key] = value
 
        if save:
            self.save_config()

from pathlib import Path
from loguru import logger
from PySide6.QtCore import QObject, QProcess, Signal
 
 
class GitManager(QObject):
    """Manages Git repository versioning lifecycle, staging, commits, and remote synchronization."""
 
    operation_started = Signal(str)  # op_name
    operation_finished = Signal(str, str)  # op_name, output
    operation_failed = Signal(str, str)  # op_name, error
    status_updated = Signal(dict)  # repo status dict
 
    def __init__(self, vault_manager=None, parent=None):
        super().__init__(parent)
        self.vault_manager = vault_manager
        self.process: QProcess | None = None
        self._current_op = ""
 
    def get_vault_path(self) -> Path | None:
        """Returns the active vault root directory."""
        if not self.vault_manager or not self.vault_manager.active_vault_path:
            return None
        return Path(self.vault_manager.active_vault_path)
 
    def _run_git_cmd(self, args: list[str], op_name: str) -> bool:
        """Executes a git CLI command asynchronously in the active vault directory using QProcess."""
        vault_path = self.get_vault_path()
        if not vault_path:
            logger.error("Cannot run Git command: No active vault path loaded.")
            return False
 
        if self.process and self.process.state() != QProcess.ProcessState.NotRunning:
            logger.warning(f"Git operation '{self._current_op}' is currently running. Busy.")
            return False
 
        self._current_op = op_name
        self.operation_started.emit(op_name)
 
        self.process = QProcess(self)
        self.process.setWorkingDirectory(str(vault_path))
 
        self.process.readyReadStandardOutput.connect(self._handle_stdout)
        self.process.readyReadStandardError.connect(self._handle_stderr)
        self.process.finished.connect(self._handle_finished)
 
        logger.info(f"Running Git command [{op_name}]: git {' '.join(args)}")
        self.process.start("git", args)
        return True
 
    def init_repository(self) -> bool:
        """Initializes a new Git repository in the active vault root."""
        return self._run_git_cmd(["init"], "init")
 
    def stage_all(self) -> bool:
        """Stages all pending workspace modifications (`git add -A`)."""
        return self._run_git_cmd(["add", "-A"], "stage_all")
 
    def create_commit(self, message: str) -> bool:
        """Snapshots staged changes into a Git commit."""
        clean_msg = message.strip() or "Auto-update knowledge vault snapshot"
        return self._run_git_cmd(["commit", "-m", clean_msg], "commit")
 
    def set_remote_origin(self, remote_url: str) -> bool:
        """Sets or updates the remote 'origin' repository URL."""
        # Try adding origin first
        return self._run_git_cmd(["remote", "add", "origin", remote_url], "set_remote")
 
    def push_changes(self, branch: str = "main") -> bool:
        """Pushes local commits upstream to remote origin."""
        return self._run_git_cmd(["push", "-u", "origin", branch], "push")
 
    def pull_changes(self, branch: str = "main") -> bool:
        """Fetches and merges upstream remote changes into the local vault."""
        return self._run_git_cmd(["pull", "origin", branch], "pull")
 
    def refresh_status(self) -> bool:
        """Queries `git status --porcelain` to evaluate workspace modification state."""
        return self._run_git_cmd(["status", "--porcelain", "-b"], "status")
 
    def _handle_stdout(self):
        if self.process:
            raw_data = self.process.readAllStandardOutput().data()
            raw_bytes = bytes(raw_data) if not isinstance(raw_data, bytes) else raw_data
            output = raw_bytes.decode("utf-8", errors="replace").strip()
            if output:
                logger.debug(f"[Git Stdout]: {output}")
 
    def _handle_stderr(self):
        if self.process:
            raw_data = self.process.readAllStandardError().data()
            raw_bytes = bytes(raw_data) if not isinstance(raw_data, bytes) else raw_data
            output = raw_bytes.decode("utf-8", errors="replace").strip()
            if output:
                logger.warning(f"[Git Stderr]: {output}")
 
    def _handle_finished(self, exit_code: int, exit_status):
        if self.process:
            raw_stdout = bytes(self.process.readAllStandardOutput().data()).decode("utf-8", errors="replace")
            raw_stderr = bytes(self.process.readAllStandardError().data()).decode("utf-8", errors="replace")
            combined_output = f"{raw_stdout}\n{raw_stderr}".strip()
 
            if exit_code == 0:
                logger.success(f"Git operation '{self._current_op}' completed successfully.")
                self.operation_finished.emit(self._current_op, combined_output)
 
                # Parse status output if status query finished
                if self._current_op == "status":
                    self._parse_status_payload(raw_stdout)
            else:
                logger.error(f"Git operation '{self._current_op}' failed with code {exit_code}.")
                self.operation_failed.emit(self._current_op, combined_output)
 
        self._current_op = ""
 
    def _parse_status_payload(self, status_text: str):
        """Parses `git status --porcelain -b` output into a structured status dict."""
        lines = status_text.strip().splitlines()
        branch = "unknown"
        modified_files = []
        untracked_files = []
 
        for line in lines:
            if line.startswith("##"):
                branch = line.replace("##", "").strip()
            elif line.startswith(" M") or line.startswith("M "):
                modified_files.append(line[3:].strip())
            elif line.startswith("??"):
                untracked_files.append(line[3:].strip())
 
        status_dict = {
            "branch": branch,
            "modified": modified_files,
            "untracked": untracked_files,
            "clean": len(modified_files) == 0 and len(untracked_files) == 0,
        }
        self.status_updated.emit(status_dict)

class SpatialGraphWidget(QGraphicsView):
    """Force-directed 2D Spatial Knowledge Network Canvas."""
 
    node_selected = Signal(str)  # Emits node_id on selection
 
    def __init__(self, parent=None):
        super().__init__(parent)
 
        self.scene_obj = QGraphicsScene(self)
        self.setScene(self.scene_obj)
 
        self.nodes_map: Dict[str, GraphNodeItem] = {}
        self.edges_list: List[GraphEdgeItem] = []
 
        # Configure Rendering Engine
        self.setRenderHints(
            QPainter.RenderHint.Antialiasing
            | QPainter.RenderHint.SmoothPixmapTransform
        )
        self.setViewportUpdateMode(
            QGraphicsView.ViewportUpdateMode.FullViewportUpdate
        )

        )
        self.setVerticalScrollBarPolicy(Qt.ScrollBarPolicy.ScrollBarAlwaysOff)
        self.setTransformationAnchor(
            QGraphicsView.ViewportAnchor.AnchorUnderMouse
        )
        self.setResizeAnchor(QGraphicsView.ViewportAnchor.AnchorUnderMouse)
        self.setBackgroundBrush(QBrush(QColor("#11111b")))
 
        # Force-Directed Physics Timer
        self.timer = QTimer(self)
        self.timer.setInterval(20)  # ~50 FPS
        self.timer.timeout.connect(self._run_force_simulation_step)

        self._is_panning = False
        self._pan_start = QPointF()
 
    def populate_graph(self, graph_data: Dict):
        """Clears existing layout and constructs visual nodes and edges from LinkEngine payload."""
        self.timer.stop()
        self.scene_obj.clear()
        self.nodes_map.clear()
        self.edges_list.clear()
 
        nodes = graph_data.get("nodes", [])
        edges = graph_data.get("edges", [])
 
        if not nodes:
            return
 
        # 1. Spawn Nodes in Initial Circular / Random Dispersion
        num_nodes = len(nodes)
        radius = max(200.0, num_nodes * 25.0)
 
        for idx, node_info in enumerate(nodes):
            node_id = node_info["id"]
            title = node_info.get("title", node_id)
            folder = node_info.get("folder", "general")
 
            angle = (2 * math.pi * idx) / num_nodes
            initial_x = radius * math.cos(angle) + random.uniform(-20, 20)
            initial_y = radius * math.sin(angle) + random.uniform(-20, 20)
 
            node_item = GraphNodeItem(node_id, title, folder=folder)
            node_item.setPos(initial_x, initial_y)
            self.scene_obj.addItem(node_item)
            self.nodes_map[node_id] = node_item
 
        # 2. Spawn Edges
        for edge_info in edges:
            src_id = edge_info["source"]
            tgt_id = edge_info["target"]
 
            if src_id in self.nodes_map and tgt_id in self.nodes_map:
                edge_item = GraphEdgeItem(
                    self.nodes_map[src_id], self.nodes_map[tgt_id]
                )
                self.scene_obj.addItem(edge_item)
                self.edges_list.append(edge_item)
 
        # 3. Start Simulation
        self.timer.start()
        QTimer.singleShot(100, self.fit_to_screen)
 
    def _run_force_simulation_step(self):
        """Executes a single iteration of Coulomb Repulsion and Hooke Attraction."""
        nodes = list(self.nodes_map.values())
        if not nodes:

        # Simulation Constants
        repulsion = 4000.0
        attraction = 0.05
        damping = 0.85
        max_displacement = 15.0
 
        # Calculate Coulomb Repulsion (All node pairs)
        for i in range(len(nodes)):
            for j in range(i + 1, len(nodes)):
                n1 = nodes[i]
                n2 = nodes[j]
 
                dx = n2.pos().x() - n1.pos().x()
                dy = n2.pos().y() - n1.pos().y()
                dist_sq = dx * dx + dy * dy + 0.1
                dist = math.sqrt(dist_sq)
 
                force = repulsion / dist_sq
                fx = (dx / dist) * force
                fy = (dy / dist) * force
 
                n1.velocity -= QPointF(fx, fy)
                n2.velocity += QPointF(fx, fx)
 
        # Calculate Hooke Attraction along edges
        for edge in self.edges_list:
            n1 = edge.source
            n2 = edge.target
 
            dx = n2.pos().x() - n1.pos().x()
            dy = n2.pos().y() - n1.pos().y()
            dist = math.sqrt(dx * dx + dy * dy) + 0.1
 
            force = dist * attraction
            fx = (dx / dist) * force
            fy = (dy / dist) * force
 
            n1.velocity += QPointF(fx, fy)
            n2.velocity -= QPointF(fx, fy)
 
        # Update Positions
        total_movement = 0.0
        for node in nodes:
            if node.isSelected():
                node.velocity = QPointF(0, 0)
                continue
 
            vx = max(
                -max_displacement, min(max_displacement, node.velocity.x())
            )
            vy = max(
                -max_displacement, min(max_displacement, node.velocity.y())
            )
 
            new_pos = node.pos() + QPointF(vx, vy)
            node.setPos(new_pos)
 
            node.velocity *= damping
            total_movement += abs(vx) + abs(vy)
 
        # Stop simulation when system stabilizes
        if total_movement < 0.5:
            self.timer.stop()

import json

from pathlib import Path
from loguru import logger
from PySide6.QtCore import QObject, Signal
 
class IngestEngine(QObject):
    """Manages Phase 1 Ingestion Queue state, file staging, and raw archive preservation."""
 
    # Signal emitted whenever queue items are added, modified, or reloaded
    queue_updated = Signal(list)
 
    QUEUE_FILENAME = "queue.json"
 
    def __init__(self, vault_manager=None, parent=None):
        super().__init__(parent)
        self.vault_manager = vault_manager
        self.queue_items: list[dict] = []
 
        if self.vault_manager:
            self.vault_manager.vault_changed.connect(self._on_vault_changed)
 
    def _on_vault_changed(self, vault_info: dict):
        """Reloads queue state when active vault changes."""
        self.load_queue()
 
    def get_queue_file_path(self) -> Path | None:
        """Returns path to wiki/.system/queue.json in active vault."""
        if not self.vault_manager or not self.vault_manager.active_vault_path:
            return None
        return (
            Path(self.vault_manager.active_vault_path)
            / "wiki"
            / ".system"
            / self.QUEUE_FILENAME
        )
 
    def load_queue(self) -> list[dict]:
        """Loads queue records from active vault's queue.json."""
        queue_path = self.get_queue_file_path()
        if not queue_path or not queue_path.exists():
            self.queue_items = []
            self.queue_updated.emit([])
            return []
 
        try:
            with open(queue_path, "r", encoding="utf-8") as f:
                self.queue_items = json.load(f)
            logger.debug(
                f"Loaded {len(self.queue_items)} items from queue.json"
            )
            self.queue_updated.emit(self.queue_items)
            return self.queue_items
        except Exception as e:
            logger.error(f"Failed to read queue.json: {e}")
            self.queue_items = []
            self.queue_updated.emit([])
            return []
 
    def save_queue(self) -> bool:
        """Persists current in-memory queue to queue.json."""
        queue_path = self.get_queue_file_path()
        if not queue_path:
            logger.error("Cannot save queue: No active vault path.")
            return False
 
        try:
            queue_path.parent.mkdir(parents=True, exist_ok=True)
            with open(queue_path, "w", encoding="utf-8") as f:
                json.dump(self.queue_items, f, indent=2)
            self.queue_updated.emit(self.queue_items)
            return True
        except Exception as e:
            logger.error(f"Failed to write queue.json: {e}")
            return False
 
    def enqueue_file(self, source_file_path: str | Path) -> dict | None:
        """Stages an incoming raw file, archives source, and writes a QUEUED record."""
        if not self.vault_manager or not self.vault_manager.active_vault_path:
            logger.error("Cannot enqueue file: No active vault loaded.")
            return None
 
        src_path = Path(source_file_path).resolve()
        if not src_path.exists():
            logger.error(f"Ingestion source file does not exist: {src_path}")
            return None
 
        vault_root = Path(self.vault_manager.active_vault_path)
        raw_dir = vault_root / "raw"
        archive_dir = raw_dir / ".sources"
        raw_dir.mkdir(parents=True, exist_ok=True)
        archive_dir.mkdir(parents=True, exist_ok=True)
 
        now = datetime.now(timezone.utc)
        date_str = now.strftime("%Y-%m-%d")
        timestamp_iso = now.isoformat()
 
        # Generate clean slug
        clean_stem = re.sub(
            r"[^\w\-_]", "_", src_path.stem.lower()
        ).strip("_")
        slug_filename = f"{date_str}_{clean_stem}{src_path.suffix}"
 
        target_raw_path = raw_dir / slug_filename
        archive_file_path = archive_dir / src_path.name
 
        # 1. Archive original source file & stage raw working payload
        try:
            shutil.copy2(src_path, archive_file_path)
            shutil.copy2(src_path, target_raw_path)
            logger.info(f"Staged raw file: {target_raw_path.name}")
        except Exception as e:
            logger.error(f"Failed staging raw files for {src_path}: {e}")
            return None
 
        # 2. Build Queue Record
        item_id = f"ingest_{now.strftime('%Y%m%d_%H%M%S')}_{len(self.queue_items) + 1:03d}"
        queue_item = {
            "id": item_id,
            "title": clean_stem.replace("_", " ").title(),
            "raw_path": str(target_raw_path.relative_to(vault_root)),
            "archive_path": str(archive_file_path.relative_to(vault_root)),
            "status": "QUEUED",  # QUEUED -> PARSING -> ANALYZING -> CASCADE -> LINKING -> COMPLETED
            "timestamp": timestamp_iso,
            "error": None,
        }
 
        self.queue_items.append(queue_item)
        self.save_queue()
        logger.success(f"Successfully enqueued payload [{item_id}]")
        return queue_item
 
    def update_item_status(
        self, item_id: str, new_status: str, error_msg: str | None = None
    ) -> bool:
        """Updates status of a specific queue record."""
        for item in self.queue_items:
            if item["id"] == item_id:
                item["status"] = new_status
                if error_msg:
                    item["error"] = error_msg
                logger.info(f"Queue item [{item_id}] state -> {new_status}")
                return self.save_queue()
        return False

import re

import networkx as nx
from loguru import logger
from PySide6.QtCore import QObject, QThread, Signal
 
 
class WikilinkParser:
    """Utility class to extract and normalize Obsidian-style [[wikilink]] references."""
 
    WIKILINK_REGEX = re.compile(r"\[\[([^\]\|]+)(?:\|([^\]]+))?\]\]")
 
    @classmethod
    def extract_links(cls, text: str) -> list[str]:
        """Extracts target link slugs or note titles from raw text."""
        matches = cls.WIKILINK_REGEX.findall(text)
        return [match[0].strip() for match in matches if match[0].strip()]
 
    @classmethod
    def slugify(cls, text: str) -> str:
        """Standardizes a title or path string to a clean comparison slug."""
        return re.sub(r"[^\w\-_]", "-", text.lower()).strip("-")
 
 
class LinkGraphWorker(QThread):
    """Background thread using NetworkX to build directed graphs and calculate metrics."""
 
    progress = Signal(str)
    finished = Signal(dict)
    error = Signal(str)
 
    def __init__(self, vault_root: Path, max_degrees: int = 3, parent=None):
        super().__init__(parent)
        self.vault_root = vault_root
        self.max_degrees = max_degrees
 
    def run(self):
        wiki_dir = self.vault_root / "wiki"
        if not wiki_dir.exists():
            self.error.emit(f"Wiki directory does not exist at {wiki_dir}")
            return
 
        self.progress.emit("Phase 1/3: Scanning wiki notes for [[wikilink]] references...")
 
        # 1. Instantiate NetworkX Directed Graph
        graph = nx.DiGraph()
        file_map: dict[str, Path] = {}
 
        try:
            md_files = [
                p for p in wiki_dir.rglob("*.md") if ".system" not in p.parts
            ]
 
            # Step A: Populate nodes in NetworkX graph
            for file_path in md_files:
                rel_path_str = str(file_path.relative_to(wiki_dir).with_suffix(""))
                slug = WikilinkParser.slugify(file_path.stem)
                
                file_map[slug] = file_path
 
                # Add node with metadata attributes
                graph.add_node(
                    slug,
                    title=file_path.stem,
                    relative_path=rel_path_str,
                    folder=file_path.parent.name,
                )
 
            self.progress.emit(f"Phase 2/3: Mapping directional edges across {graph.number_of_nodes()} nodes...")
 
            # Step B: Parse content and add directional edges
            for slug, file_path in file_map.items():
                content = file_path.read_text(encoding="utf-8")
                extracted = WikilinkParser.extract_links(content)
 
                for link_target in extracted:
                    target_slug = WikilinkParser.slugify(link_target)
                    # Create target node dynamically if it doesn't exist yet
                    if not graph.has_node(target_slug):
                        graph.add_node(
                            target_slug,
                            title=link_target,
                            relative_path=f"uncreated/{target_slug}",
                            folder="uncreated",
                        )
                    graph.add_edge(slug, target_slug)
 
            self.progress.emit(f"Phase 3/3: Computing NetworkX path metrics (Max Degrees = {self.max_degrees})...")
 
            # Step C: Compute NetworkX Graph Analytics
            isolated_nodes = list(nx.isolates(graph))
            
            # Compute shortest paths and flag degree violations (> max_degrees)
            exceeded_pairs = []
            all_shortest_paths = dict(nx.all_pairs_shortest_path_length(graph))
 
            for source, targets in all_shortest_paths.items():
                for target, distance in targets.items():
                    if source != target and distance > self.max_degrees:
                        exceeded_pairs.append((source, target, distance))
 
            # Serialized Graph Data Payload for UI / Visualizer
            graph_data = {
                "total_nodes": graph.number_of_nodes(),
                "total_edges": graph.number_of_edges(),
                "nodes": [
                    {
                        "id": node,
                        "title": graph.nodes[node].get("title", node),
                        "folder": graph.nodes[node].get("folder", "general"),
                        "in_degree": graph.in_degree(node),
                        "out_degree": graph.out_degree(node),
                    }
                    for node in graph.nodes
                ],
                "edges": [
                    {"source": u, "target": v} for u, v in graph.edges
                ],
                "isolated_nodes": isolated_nodes,
                "exceeded_boundary_count": len(exceeded_pairs),
            }
 
            self.finished.emit(graph_data)
 
        except Exception as e:
            logger.exception(f"NetworkX link graph construction failed: {e}")
            self.error.emit(str(e))

    """Pydantic model enforcing required GEO frontmatter attributes."""
 
    title: str
    slug: str
    type: str  # "source", "entity", "concept", "synthesis"
    tags: List[str] = Field(default_factory=list)
    sources: List[str] = Field(default_factory=list)
    created: str
    updated: str
    confidence: float = 1.0
    status: str = "active"
 
 
class LintWorker(QThread):
    """Background thread executing deterministic structural and semantic health audits."""
 
    progress = Signal(str)
    finished = Signal(dict)
    error = Signal(str)
 
    def __init__(self, vault_root: Path, llm_config: dict, parent=None):
        super().__init__(parent)
        self.vault_root = vault_root
        self.llm_config = llm_config
        self.client = LlamaClient(
            base_url=llm_config.get("endpoint", "http://127.0.0.1:8080/v1")
        )
 
    def run(self):
        wiki_dir = self.vault_root / "wiki"
        if not wiki_dir.exists():
            self.error.emit(f"Wiki directory does not exist at {wiki_dir}")
            return
 
        self.progress.emit(
            "Phase 1/3: Validating YAML Frontmatter & Schema via python-frontmatter & Pydantic..."
        )
 
        broken_links: List[Dict[str, str]] = []
        invalid_frontmatter: List[Dict[str, str]] = []
        valid_slugs: Set[str] = set()
        file_map: Dict[str, Path] = {}
 
        try:
            # 1. Discover all active Markdown notes
            md_files = [
                p for p in wiki_dir.rglob("*.md") if ".system" not in p.parts
            ]
 
            for file_path in md_files:
                slug = WikilinkParser.slugify(file_path.stem)
                valid_slugs.add(slug)
                file_map[slug] = file_path
 
            # 2. Inspect Frontmatter and Links
            for file_path in md_files:
                rel_path = str(file_path.relative_to(self.vault_root))
 
                # Load frontmatter safely
                try:
                    post = frontmatter.load(file_path)
                except Exception as fe:
                    invalid_frontmatter.append(
                        {
                            "path": rel_path,
                            "reason": f"Failed to load Markdown file: {fe}",
                        }
                    )
                    continue
 
                # Type-safe metadata dictionary conversion for Pydantic & Pylance
                raw_metadata: Dict[str, Any] = dict(post.metadata)
 
                try:
                    WikiFrontmatterSchema(**raw_metadata)
                except yaml.YAMLError as ye:
                    invalid_frontmatter.append(
                        {"path": rel_path, "reason": f"YAML Syntax Error: {ye}"}
                    )
                except Exception as pe:
                    invalid_frontmatter.append(
                        {
                            "path": rel_path,
                            "reason": f"Schema Validation Failed: {pe}",
                        }
                    )
 
                # Extract and verify [[wikilinks]] (post is now guaranteed bound)
                extracted_links = WikilinkParser.extract_links(str(post.content))
                for link in extracted_links:
                    target_slug = WikilinkParser.slugify(link)
                    if target_slug not in valid_slugs:
                        broken_links.append(
                            {"source": rel_path, "target": link}
                        )
 
            self.progress.emit(
                f"Phase 2/3: Evaluated {len(md_files)} files — Found {len(broken_links)} broken links and {len(invalid_frontmatter)} schema violations."
            )
 
            # 3. Compute Structural Graph Metrics with NetworkX
            graph = nx.DiGraph()
            for slug in valid_slugs:
                graph.add_node(slug)
 
            for slug, file_path in file_map.items():
                content = file_path.read_text(encoding="utf-8")
                for link in WikilinkParser.extract_links(content):
                    target_slug = WikilinkParser.slugify(link)
                    if target_slug in valid_slugs:
                        graph.add_edge(slug, target_slug)
 
            isolated_notes = [
                str(file_map[slug].relative_to(self.vault_root))
                for slug in nx.isolates(graph)
                if slug in file_map
            ]
 
            # 4. Phase 3: Final Health Report Generation
            self.progress.emit("Phase 3/3: Finalizing system health score...")
 
            deductions = (
                (len(broken_links) * 5)
                + (len(invalid_frontmatter) * 3)
                + (len(isolated_notes) * 2)
            )
            health_score = max(0, 100 - deductions)
 
            report = {
                "total_notes": len(md_files),
                "health_score": health_score,
                "broken_links": broken_links,
                "invalid_frontmatter": invalid_frontmatter,
                "isolated_notes": isolated_notes,
            }
 
            self.finished.emit(report)
 
        except Exception as e:
            logger.exception(f"Wiki lint pass failed: {e}")
            self.error.emit(str(e))
 
 
class LintEngine(QObject):
    """High-level Orchestrator for Phase 3 /wiki-lint system integrity operations."""
 
    lint_started = Signal()

from PySide6.QtCore import QObject, Signal
 
class QtLogSink(QObject):
    """PySide6 Signal Bridge to route Loguru output directly into UI log widgets."""
 
    log_emitted = Signal(str)
 
    def __init__(self, parent=None):
        super().__init__(parent)
        self._is_emitting = False
 
    def write(self, message: str):
        # Guard against Shiboken C++ signature loader recursion loop
        if self._is_emitting:
            return
        self._is_emitting = True
        try:
            # Strip trailing newlines for clean QTextEdit appending
            msg = message.strip()
            if msg:
                self.log_emitted.emit(msg)
        finally:
            self._is_emitting = False
 
 
# Global Qt Sink instance
qt_log_sink = QtLogSink()
 
def setup_logger(vault_path: Path | str | None = None):
    """Configures Loguru logging format, file sinks, and Qt signal bridges."""
    logger.remove()  # Remove default handler
 
    # Custom string-based format to bypass Loguru's internal datetime formatter
    console_format = (
        "{time:YYYY-MM-DD HH:mm:ss} | <level>{level: <8}</level> | "
        "<cyan>{name}</cyan>:<cyan>{function}</cyan>:<cyan>{line}</cyan> - <level>{message}</level>\n"
    )
 
    qt_format = "{time:HH:mm:ss} | {level: <7} | {message}\n"
 
    # 1. Console Output Sink (pre-formatted datetime string)
    logger.add(
        sys.stderr,
        format=console_format,
        level="INFO",
        catch=True,
    )
 
    # 2. PySide6 Custom Qt Log Sink
    logger.add(
        qt_log_sink.write,
        format=qt_format,
        level="INFO",
        catch=True,  # Prevent loguru exceptions from collapsing the UI thread
    )
 
    # 3. Persistent File Sink (If active vault directory provided)
    if vault_path:
        log_file = f"{vault_path}/pipeline.log"
        logger.add(
            log_file,
            retention="7 days",
            compression="zip",
            format="{time:YYYY-MM-DD HH:mm:ss} | {level: <8} | {name}:{function}:{line} - {message}",
            level="DEBUG",
            rotation="10 MB",
            encoding="utf-8",

from pathlib import Path
import sys
from loguru import logger
from PySide6.QtCore import QObject, QProcess, Signal
 
 
class MCPManager(QObject):
    """Manages the background execution lifecycle (Start/Stop/Restart) of mcp_server.py."""
 
    server_started = Signal(str)
    server_stopped = Signal()
    server_log = Signal(str)
 
    def __init__(self, vault_manager=None, parent=None):
        super().__init__(parent)
        self.vault_manager = vault_manager
        self.process: QProcess | None = None
        self.transport = "stdio"
        self.host = "127.0.0.1"
        self.port = 8001
 
    def configure_network(
        self, host: str = "127.0.0.1", port: int = 8001, transport: str = "stdio"
    ):
        self.host = host
        self.port = port
        self.transport = transport
 
    def start_server(self) -> bool:
        """Launches mcp_server.py as an asynchronous QProcess subprocess."""
        if (
            self.process
            and self.process.state() != QProcess.ProcessState.NotRunning
        ):
            logger.warning("MCP Server process is already running.")
            return False
 
        if not self.vault_manager or not self.vault_manager.active_vault_path:
            logger.error("Cannot start MCP server: No active vault path set.")
            return False
 
        vault_path = str(self.vault_manager.active_vault_path)
        python_executable = sys.executable
 
        server_script = Path(__file__).parent / "mcp_server.py"
        if not server_script.exists():
            logger.error(f"Missing mcp_server.py at {server_script}")
            return False
 
        args = [
            str(server_script),
            "--vault",
            vault_path,
            "--transport",
            self.transport,
            "--host",
            self.host,
            "--port",
            str(self.port),
        ]
 
        self.process = QProcess(self)
        self.process.readyReadStandardOutput.connect(self._handle_stdout)
        self.process.readyReadStandardError.connect(self._handle_stderr)
        self.process.finished.connect(self._handle_finished)
 
        self.process.start(python_executable, args)
 
        info = (
            f"{self.transport.upper()} mode on {self.host}:{self.port}"
            if self.transport == "sse"
            else "STDIO mode"
        )
        logger.info(f"Starting MCP Server subprocess: {info}")
        self.server_started.emit(info)
        return True
 
    def stop_server(self) -> bool:
        """Terminates the running MCP Server process."""
        if (
            not self.process
            or self.process.state() == QProcess.ProcessState.NotRunning
        ):
            logger.info("MCP Server is not running.")
            return False
 
        logger.info("Stopping MCP Server subprocess...")
        self.process.terminate()
        if not self.process.waitForFinished(2000):
            self.process.kill()
        return True
 
    def restart_server(self) -> bool:
        """Restarts the MCP Server subprocess."""
        self.stop_server()
        return self.start_server()
 
    def _handle_stdout(self):
        if self.process:
            raw_data = self.process.readAllStandardOutput().data()
            raw_bytes = bytes(raw_data) if not isinstance(raw_data, bytes) else raw_data
            data = raw_bytes.decode("utf-8", errors="replace").strip()
            if data:
                logger.debug(f"[MCP Server Out]: {data}")
                self.server_log.emit(data)
 
    def _handle_stderr(self):
        if self.process:
            raw_data = self.process.readAllStandardError().data()
            raw_bytes = bytes(raw_data) if not isinstance(raw_data, bytes) else raw_data
            data = raw_bytes.decode("utf-8", errors="replace").strip()
            if data:
                logger.warning(f"[MCP Server Err]: {data}")
                self.server_log.emit(data)
 
    def _handle_finished(self, exit_code, exit_status):
        logger.info(f"MCP Server process exited with code {exit_code}")
        self.server_stopped.emit()

# vault_manager.py
 
import json
from datetime import datetime, timezone
from pathlib import Path
from loguru import logger
from PySide6.QtCore import QObject, Signal
 
class VaultManager(QObject):
    """Manages creation, validation, loading, and state tracking for LLM Wiki Vaults."""
 
    # Signal emitted when a vault is loaded or created successfully
    vault_changed = Signal(dict)
 
    CONFIG_FILENAME = ".llm-wiki-config"
    APP_CONFIG_DIR = Path.home() / ".config" / "LLM-Wiki-Qt"
    RECENT_VAULTS_FILE = APP_CONFIG_DIR / "recent_vaults.json"
 
    def __init__(self, parent=None):
        super().__init__(parent)
        self.active_vault_path: Path | None = None
        self.active_config: dict = {}
        self.APP_CONFIG_DIR.mkdir(parents=True, exist_ok=True)
 
    def initialize_vault(
        self, vault_dir: str | Path, name: str, description: str
    ) -> bool:
        """Instantiates the required directory tree and default system files for a new vault."""
        root = Path(vault_dir).resolve()
        logger.info(f"Initializing new vault'{name}' at {root}")
        root.mkdir(parents=True, exist_ok=True)
 
        # 1. Core Directory Schema
        directories = [
            root / "raw",
            root / "raw" / ".sources",
            root / "wiki",
            root / "wiki" / "sources",
            root / "wiki" / "entities",
            root / "wiki" / "concepts",
            root / "wiki" / "synthesis",
            root / "wiki" / ".system",
            root / "wiki" / ".system" / "prompts",
        ]
        for d in directories:
            d.mkdir(parents=True, exist_ok=True)
 
        # 2. Generate `.llm-wiki-config`
        config_data = {
            "vault_name": name,
            "domain_description": description,
            "version": "1.0",
            "created_at": datetime.now(timezone.utc).isoformat(),
            "settings": {
                "auto_watch_raw": True,
                "max_link_degrees": 3,
                "default_llm_model": "qwen2.5-coder-14b",
            },
        }
        config_path = root / self.CONFIG_FILENAME
        with open(config_path, "w", encoding="utf-8") as f:
            json.dump(config_data, f, indent=2)
 
        # 3. Generate baseline vault files
        index_path = root / "wiki" / "index.md"
        if not index_path.exists():
            index_path.write_text(
                f"# {name} - Master Catalog\n\n> {description}\n\n## Sources\n\n## Entities\n\n## Concepts\n\n## Synthesis\n",
                encoding="utf-8",
            )
 
        log_path = root / "wiki" / "log.md"
        if not log_path.exists():
            now_str = datetime.now(timezone.utc).strftime("%Y-%m-%d %H:%M:%S")
            log_path.write_text(
                f"# Vault Activity Log\n\n- [{now_str}] Initialized vault '{name}'.\n",
                encoding="utf-8",
            )
 
        queue_path = root / "wiki" / ".system" / "queue.json"
        if not queue_path.exists():
            queue_path.write_text("[]", encoding="utf-8")
 
        schema_path = root / "SCHEMA.md"
        if not schema_path.exists():
            schema_path.write_text(
                f"# Operational Schema for {name}\n\n"
                f"Domain Description: {description}\n\n"
                "## Rules\n"
                "- Source documents in `raw/` are immutable.\n"
                "- All section chunks must observe 200–400 word boundaries.\n"
                "- Wikilink degrees of separation limit = 3.\n",
                encoding="utf-8",
            )
 
        logger.success(f"Vault directory structure instantiated for '{name}'")
 
        # 4. Load initialized vault
        return self.load_vault(root)
 
    def load_vault(self, vault_dir: str | Path) -> bool:
        """Validates and loads an existing vault path."""
        root = Path(vault_dir).resolve()
        config_path = root / self.CONFIG_FILENAME
 
        if not config_path.exists():
            logger.error(f"No {self.CONFIG_FILENAME} found at {root}")
            return False
 
        try:
            with open(config_path, "r", encoding="utf-8") as f:
                self.active_config = json.load(f)
            self.active_vault_path = root
 
            # Update recent vaults list
            self._add_to_recent(str(root))
 
            # Emit state change payload
            payload = {
                "path": str(root),
                "name": self.active_config.get("vault_name", root.name),
                "description": self.active_config.get("domain_description", ""),
                "config": self.active_config,
            }
            self.vault_changed.emit(payload)
            logger.success(f"Active vault set to: '{payload['name']}' ({root})")
            return True
 
        except Exception as e:
            logger.exception(f"Failed to load vault config at {root}: {e}")
            return False
 
    def _add_to_recent(self, path_str: str):
        """Maintains the recent vaults list in user config."""
        recents = self.get_recent_vaults()
        if path_str in recents:
            recents.remove(path_str)
        recents.insert(0, path_str)
        recents = recents[:10]  # Keep top 10
 
        with open(self.RECENT_VAULTS_FILE, "w", encoding="utf-8") as f:
            json.dump(recents, f, indent=2)
 
    def get_recent_vaults(self) -> list[str]:
        """Returns list of recently accessed vault directory paths."""
        if not self.RECENT_VAULTS_FILE.exists():
            return []
        try:
            with open(self.RECENT_VAULTS_FILE, "r", encoding="utf-8") as f:
                return json.load(f)
        except Exception:
            return []
